COWORKING CARDS INFORMATION - 12 CITIES
=======================================
Source: src/pages/<city>/<city>Data.js (counted from the data files, nothing in the code was changed).

HOW TO READ THIS FILE
- Main cards      = cards shown on the city page in the normal "All" view (listing pages 1,2,3...).
                    "Unique" = same coworking name counted once (some data repeats a card).
- Sub-locations   = the area buttons / filter tiles of the city page (the "All" button is not counted).
- Cards per area  = main cards whose area is that sub-location.
- Extra cards     = cards that are NOT in the main listing and appear ONLY when a user clicks that
                    sub-location (from areaExtraOfficeCards / similar cards). Extra cards are hidden in the "All" view.
- Shown on click  = main cards of that area + extra cards of that area (what the user sees after clicking the area).
- Cards not under any sub-location = main cards whose area is not in the sub-location list;
                    they show only in the "All" view.
